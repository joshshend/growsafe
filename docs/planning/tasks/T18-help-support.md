# T18 Help & Support tab (borrowed from CareLoop: financial-assistance links with application forms; SafeZone: "find help near you")
Build the Help tab as a real, useful directory, not a link dump.
Data: src/help/resources.json + Zod schema src/help/schema.ts (+ validator wired into `npm run kb:validate`). Entry: id, title, what (1 sentence), who it's for (1 sentence), cost ("Free"/"Low cost"), category (emergency | car_seat | sleep | home_safety_gear | health_coverage | food | caregiver_support | child_care), scope ("national" | "texas" | county slug), url (official page, https), apply_url? (direct application page), phone?, source_publisher, last_verified (ISO date you opened the page), verified: boolean. NOTHING ships as verified:true unless you opened the official page this session. Entries to research (official sources only): Poison Help (poisonhelp.org, 1-800-222-1222); 211 Texas (211texas.org); Texas Health and Human Services: WIC, CHIP/Children's Medicaid (apply_url = the official Your Texas Benefits / YourTexasBenefits.com page); Safe Kids / local car seat check events and inspection stations (safekids.org, NHTSA car seat inspection station locator); Cribs for Kids / safe sleep crib programs (cribsforkids.org) and any Texas or Austin/Travis County program you can verify; smoke and CO alarm free-install programs (Austin Fire Department or Travis County, only if verifiable); Postpartum Support International helpline (postpartum.net) and 988 for caregivers in crisis (links only, no screening or advice); Texas Child Care / Head Start finder (official). Target 12 to 18 entries.
UI (src/ui, Help tab): top: red Poison Help call button + "In an emergency call 911"; "Free and low-cost help" list grouped by category with filter chips (Near me: Texas / National); each row: title, who it helps, cost chip, buttons "Open site" and "Apply" (when apply_url); a muted "Checked on <date>" line; entries with verified:false show "Not checked recently" and are sorted last. Zip code field (stored locally, optional) used only to sort Texas entries and prefill the 211 / car seat locator links where those sites accept it; if not, just open the page. Offline: list works offline. No ads, no tracking, no affiliate links.
Tasks: from the plan, a task can link to a Help entry (e.g. "Free car seat check" attaches car_seat entries) via a `help_ids[]` on KB entries only if you can do it without touching src/kb schema tests; otherwise skip.
Strings go in src/i18n/features/help.en.json and help.es.json ([ES] placeholders). Tests: schema + validator; list filtering; an unverified entry sorts last. Commit only your paths. Reply <150 words incl. which entries you could not verify.
