# T21 Growth preview: "what's coming" slider
A screen where the parent drags a slider from the child's current age to +18 months and watches which hazards switch on and how the plan re-ranks. Demo moment: "move the child forward and the plan changes".
Logic (src/plan/preview.ts, pure): previewAt(kb, child, monthsAhead, now) -> {ranked, newlyActive: RankedHazard[] (not active at monthsAhead-1, active now), dropped, unlocksBy: Map<month, hazards>}; reuse rankHazards with a shifted `now`. Tests: monotonic unlock; diff correctness at boundaries; 0 months equals current plan.
Content: src/kb/stages.json: for each stage, "how children this age explore" (2 to 3 plain sentences) with citation URL + accessed date from CDC "Learn the Signs. Act Early" developmental milestones or AAP HealthyChildren; mark evidence_status "verify" if you cannot open the page; never invent ages. Validate with a Zod schema and extend `kb:validate`.
UI: route /ahead (reached from the "Coming up" row on Today). Big slider labelled with age ("Maya at 14 months"), native range input with +/- buttons for accessibility, announces changes via aria-live. Below: "New at this age" list with a plain sentence per hazard ("Climbing starts: furniture and stairs move up"), the stage explore note, and a compact timeline: one row per active hazard, a bar from unlock age to the end of the horizon, severity shown by icon+word (not colour only); provide the same data as a list for screen readers. Tapping a hazard opens the normal task sheet. "Add these to my plan now" button adds upcoming tasks. No entrance animations; the slider drag itself is the motion.
Done when typecheck, lint, tests pass; reply <150 words.
