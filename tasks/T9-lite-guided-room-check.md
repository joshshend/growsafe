# T9-lite Guided room check (replaces the hosted photo scan; no AI, no keys)
Build "Room check": the user walks a room and taps what they see; GrowSafe turns it into tasks.
Pure logic in src/perception/ (keep file names from ARCHITECTURE.md): guided.ts: cuesForRoom(kb, room, child, now) -> cue list (union of detection_cues from active+upcoming hazards for that room and the child's stage, each with its hazard id, deduped, ordered by hazard rank score); findingsFromTaps(taps: string[]) -> Finding[] (confidence 1); findingsToTasks(findings, kb, home, room) -> Task[] (reuse existing task builders/ids so tasks merge with the plan, no duplicates); verifyFix(task, findingsAfter) -> 'fixed' | 'still_present' | 'cannot_tell' (cannot_tell if the cue wasn't offered). Tests for each, incl. duplicates and rooms with no cues.
Cue labels: src/i18n/features/cues.en.json and cues.es.json with a plain-language label for every cue in eval/cues.txt AND every detection_cue in src/kb/data/*.json (script test that fails if any cue lacks a label), e.g. cleaning_products_low -> "Cleaning products stored below counter height". Add an icon mapping to existing Phosphor icons (fallback generic).
UI: route /scan reached from each room page ("Check this room") and from Today. Flow: choose room (preselected) -> one screen with the cue list as large tappable rows with checkbox + icon + label (grouped, max ~12, "Show more" if longer) -> "Add N things to my plan" -> result screen: "N things added to your plan" + links to tasks, a "What this check can't see" list built from the hazards' blind_spots, and the line "Nothing flagged does not mean the room is safe." Re-check: from a task sheet, "Check again" reopens the room check at that cue; unticking marks the task done via the existing status action.
Copy: sentence case, plain, no AI mention, never "safe" as a claim. Easy mode compatible (48px+ targets). Commit only your paths. Run typecheck, lint, tests, build. Reply <150 words.
