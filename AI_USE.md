# AI use log

## Summary

- **Models used:** Claude (Anthropic), through Claude Code. The table below names the model for each file: Claude Haiku 5.5 for the initial scaffold, Claude Sonnet 5.5 for later work. Rows that say only "Claude" were written before the model name was recorded.
- **What was AI-assisted:** application code, unit and end-to-end tests, knowledge base drafts (researched from cited public sources such as CPSC, CDC, AAP and Poison Help, with each entry's source URL and access date), Spanish translations (machine translation, not reviewed by a fluent speaker), and documentation (README, task briefs, this log).
- **What the human did:** Josh set the product direction and scope, wrote the decisions recorded in `DECISIONS.md` (for example, omitting firearm storage and cutting live sync), reviewed each change, and ran the tests and the app before merging. Fix-step costs and minutes are model estimates. Knowledge base entries marked `evidence_status: "verify"` still need a human to check the figures against the cited page. The table below is the file-level detail and may lag the latest commits; `git log` is the complete record.
- **What AI did not do:** make product decisions on its own, or provide verified medical advice. Nothing in the app is a substitute for professional advice.
